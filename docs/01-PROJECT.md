# 01. Project — Detail Page Studio

상태: `Draft (TASK-001, Human 확정 대기)`

## 1. 한 줄 정의

네이버 스마트스토어 상품 상세페이지를 **분석**하고, 그 결과를 바탕으로 판매자가 자기 상품의 상세페이지를 **제작**하도록 돕는 웹 서비스.

## 2. 대상 사용자

- 1차: 스마트스토어를 운영하는 소규모 판매자
- 2차(후보): 상세페이지 제작 대행 디자이너 / 마케터

## 3. 단계별 범위 (DEC-006)

| 단계 | 내용 | 입력 |
|---|---|---|
| 1단계 | 남의 스토어(경쟁 상품) 상세페이지 분석 + 내 상세페이지 제작 | 사용자가 업로드한 상세페이지 캡처 (DEC-003) |
| 2단계 | 내 스토어 상세페이지 진단 + 경쟁 상품과 비교 | 네이버 커머스 API로 가져온 내 상품 상세 (DEC-003) |

## 4. 핵심 기능

### 4.1 상세페이지 분석

- 입력: 상세페이지 전체 캡처 이미지(긴 세로 이미지 1장 또는 여러 장) + 선택 입력(상품명, 가격, 카테고리)
- 처리: 이미지 조각 분할 → Vision 분석(DEC-004)
- 분석 결과:
  - 섹션 구조: 후킹 / 문제 제기 / 해결 / 차별점 / 근거·인증 / 상세 스펙 / 사용법 / 후기 / 배송·교환 / CTA 등
  - 섹션별 핵심 문구(OCR), 소구 포인트, 타깃, 톤
  - 신뢰 요소와 누락 요소 체크리스트
  - 점수(항목별 기준은 Gate B에서 확정)와 개선 제안
- 출력: 분석 리포트 화면, JSON 내보내기

### 4.2 상세페이지 제작

- 입력: 내 상품 정보(이름, 특징, 타깃, 가격대) + 상품 사진 + 참고할 분석 리포트(선택)
- 처리: 섹션 구성안 생성 → 섹션별 한국어 카피 생성 → 템플릿 적용
- 편집: 섹션 추가 / 삭제 / 순서 변경, 문구 수정, 이미지 교체
- 출력: 모바일 폭 미리보기, PNG 내보내기(긴 이미지 1장 + 섹션별 분할)

## 5. 1단계 MVP 포함 / 제외

| 포함 | 제외 |
|---|---|
| 캡처 업로드 분석, 분석 리포트 | 서버의 네이버 페이지 수집(크롤링) |
| 템플릿 기반 생성 + 편집 + PNG 내보내기 | 스마트스토어 자동 등록 |
| 브라우저 내 작업 임시 저장 | 로그인 / 회원 / 결제 |
| 비용 상한 / 오류 안내 | AI 이미지 생성 |

## 6. 완료 기준 (1단계)

- 캡처 업로드로 분석 리포트를 만들 수 있다
- 분석 리포트를 참고해 내 상품 상세페이지 초안을 만들고 편집 / PNG로 내보낼 수 있다
- AI API 실패 / 비용 상한 초과 / 잘못된 이미지에 대해 원인과 대안을 안내한다
- `scripts/verify.*`와 CI가 통과한다

## 7. 남은 질문 (Human)

- 월 AI 비용 상한(원)
- 분석 점수 기준(Gate B): 초안은 TASK에서 만들고 Human이 승인
- Repository Public 유지 여부 (DEC-005)
