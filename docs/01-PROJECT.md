# 01. Project — SmartStore Detail Page

상태: `Draft (TASK-001에서 Human 확정 필요)`

## 1. 한 줄 정의

네이버 스마트스토어 상품 상세페이지를 **분석**하고, 그 결과를 바탕으로 판매자가 자기 상품의 상세페이지를 **제작**하도록 돕는 웹 서비스.

## 2. 대상 사용자 (확정 필요)

- 1차: 스마트스토어를 운영하는 소규모 판매자
- 2차(후보): 상세페이지 제작 대행 디자이너 / 마케터

## 3. 핵심 기능 (초안)

### 3.1 상세페이지 분석

분석 대상 순서 (Human 결정 2026-11-03):

1. **1단계: 남의 스토어(경쟁 상품) 분석**. 공식 API가 없으므로 URL 1건 수집 또는 캡처 업로드로 입력한다(DEC-003).
2. **2단계: 내 스토어 분석(자가 진단)**. 1단계 분석 기준을 재사용하고, 내 상품 데이터는 네이버 커머스 API로 가져오는 방안을 검토한다(DEC-004 / 외부 연동 Gate).

- 입력: 상품 URL 또는 상세페이지 캡처 이미지
- 수집: 상품명, 가격, 옵션, 리뷰 수 / 평점, 상세 이미지, 상세 텍스트
- 분석: 상세 이미지 OCR / Vision 분석 → 구성 섹션(후킹, 문제 제기, 해결, 근거, 스펙, 후기, CTA 등), 소구 포인트, 키워드, 신뢰 요소, 누락 요소
- 출력: 구조 요약, 점수 / 체크리스트, 경쟁 상품 비교, 개선 제안

### 3.2 상세페이지 제작

- 입력: 내 상품 정보(이름, 특징, 타깃, 이미지) + 참고할 분석 결과
- 생성: 섹션 구성안 → 섹션별 카피 → 레이아웃 템플릿 적용
- 편집: 섹션 순서 / 문구 / 이미지 교체
- 출력: 미리보기(모바일 기준), 이미지(긴 JPG/PNG) 또는 HTML 내보내기
- (후보) 네이버 커머스 API로 내 상품 상세 등록

## 4. MVP 범위 (확정 필요)

| 포함 후보 | 제외 후보 |
|---|---|
| URL 1건 분석, 캡처 이미지 업로드 분석 | 대량 / 주기적 자동 수집 |
| 분석 리포트 화면 | 경쟁사 가격 모니터링 |
| 템플릿 기반 상세페이지 생성 + 편집 + 이미지 내보내기 | 스마트스토어 자동 등록 |
| 회원별 작업 저장(후보) | 결제 / 구독 |

## 5. 열린 질문

- 생성 결과물 형식: 이미지 한 장 / 섹션별 이미지 / HTML 중 무엇이 필수인가
- 로그인 / 저장이 MVP에 필요한가
- 월 비용 상한(LLM / Vision / 이미지 생성 API)

## 6. 완료 기준 (MVP, 초안)

- URL 또는 캡처로 분석 리포트를 생성할 수 있다
- 분석 결과를 참고해 내 상품 상세페이지 초안을 만들고 편집 / 내보내기할 수 있다
- 외부 API 실패 / 수집 차단 시 사용자에게 원인과 대안(캡처 업로드)을 안내한다
- `scripts/verify.*`와 CI가 통과한다
