# 03. UX / UI Spec

상태: `Draft (TASK-001, Human 승인 대기)`

## 1. 화면 구성 (1단계)

| 경로 | 화면 | 주요 요소 |
|---|---|---|
| `/` | 홈 | 서비스 소개, "경쟁 상세페이지 분석" / "내 상세페이지 만들기" 두 진입 버튼, 최근 작업(브라우저 저장) |
| `/analyze` | 분석 입력 | 캡처 업로드(드래그 앤 드롭, 여러 장, 순서 변경), 선택 입력(상품명 / 가격 / 카테고리), 캡처 방법 안내, 업로드 이용 안내 문구 |
| `/analyze/[id]` | 분석 리포트 | 왼쪽: 원본 캡처를 섹션별로 구분해 표시. 오른쪽: 섹션 구조 타임라인, 섹션 카드(역할 / 핵심 문구 / 소구 포인트), 체크리스트, 점수, 개선 제안. "이 구조로 내 상세페이지 만들기" 버튼 |
| `/create` | 상품 정보 입력 | 상품명, 특징(여러 줄), 타깃, 가격대, 사진 업로드, 참고 리포트 선택 |
| `/create/[id]` | 편집기 | 왼쪽: 섹션 목록(드래그 정렬, 추가 / 삭제). 가운데: 모바일 폭 미리보기. 오른쪽: 선택한 섹션의 문구 / 이미지 / 템플릿 편집. 상단: PNG 내보내기 |

## 2. 상태

| 상황 | 표시 |
|---|---|
| 분석 진행 중 | 단계 표시(이미지 분할 → 섹션 분석 → 종합), 예상 소요 시간, 취소 |
| AI API 실패 | 원인(시간 초과 / 일시 장애)과 다시 시도 버튼. 업로드 이미지는 유지 |
| 비용 상한 초과 | 이번 달 한도 도달 안내, 요청 차단 |
| 잘못된 이미지 | 지원 형식(JPG / PNG / WEBP), 최대 크기, 상세페이지가 아닌 이미지 안내 |
| 빈 상태 | 최근 작업 없음 → 예시 리포트 보기 링크 |

## 3. 반응형 / 접근성

- 앱 화면: Mobile 390px, Tablet 768px, Desktop 1280px. 편집기는 Tablet 이하에서 탭 전환(섹션 / 미리보기 / 편집).
- 생성 상세페이지: 폭 860px 기준으로 렌더링하고 모바일 미리보기는 축소 표시.
- 키보드로 섹션 이동 / 정렬 가능, 대비 WCAG AA.

## 4. 캡처 방법 안내 (분석 입력 화면에 표시)

- PC Chrome: 개발자 도구 → 명령 메뉴 → "Capture full size screenshot"
- 모바일: 스크롤 캡처 기능
- 본인이 열람한 페이지만 업로드하고, 분석 결과는 참고용으로만 사용하도록 안내한다.
