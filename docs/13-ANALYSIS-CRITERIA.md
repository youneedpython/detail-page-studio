# 13. 상세페이지 분석 기준 (Gate B)

상태: `Approved (DEC-009, Claude 세션 결정 2026-11-03, DEC-008 위임)`. 변경은 Gate B 대상이다.

분석 엔진(TASK-005)의 Prompt와 결과 Schema는 이 문서를 기준으로 한다. 기준은 상세페이지 일반론(첫 화면 후킹 → 문제 공감 → 해결 → 근거 → 정보 → 구매 유도)을 따르며, 실제 사용 후 Human 피드백으로 조정한다.

## 1. 섹션 역할 (`SectionRole`)

| role | 이름 | 판단 기준 |
|---|---|---|
| `hook` | 후킹 | 첫 화면. 대표 혜택 / 강한 카피 / 대표 이미지로 스크롤을 멈추게 함 |
| `problem` | 문제 제기 | 고객의 불편 / 고민 / 상황 공감 |
| `solution` | 해결 | 상품이 문제를 어떻게 해결하는지, 핵심 기능 |
| `differentiator` | 차별점 | 경쟁 상품 대비 우위, 비교 |
| `proof` | 근거 · 신뢰 | 인증서, 시험 성적, 수치, 수상, 판매량, 언론 |
| `spec` | 상세 스펙 | 소재, 크기, 용량, 구성품, 옵션 |
| `usage` | 사용법 | 사용 순서, 활용 장면, 관리 방법 |
| `review` | 후기 | 고객 후기 캡처, 평점, 사용 사진 |
| `shipping` | 배송 · 교환 | 배송, 교환 / 반품, A/S, 주의사항 |
| `cta` | 구매 유도 | 혜택 재강조, 한정 / 이벤트, 구매 권유 |
| `other` | 기타 | 브랜드 소개, FAQ 등 위에 없는 것 |

## 2. 이미지 종류 (`visuals.kind`)

`model`(모델 착용 / 사용컷), `product_cutout`(누끼 / 단독 제품컷), `lifestyle`(연출 / 사용 장면), `detail_closeup`(디테일 확대), `infographic`(아이콘 · 도식 · 수치 그래픽), `comparison`(비교표 / 비포·애프터), `certificate`(인증서 / 성적서), `review_capture`(후기 캡처), `other`

## 3. 체크리스트 (고정 10항목)

| item | 확인 내용 |
|---|---|
| 대표 혜택 한 줄 | 첫 화면에서 핵심 혜택이 한 문장으로 보이는가 |
| 타깃 명확성 | 누구를 위한 상품인지 드러나는가 |
| 사용 장면 | 실제 사용 / 착용 장면 이미지가 있는가 |
| 차별점 | 경쟁 상품과 다른 점을 말하는가 |
| 객관적 근거 | 인증 / 수치 / 시험 결과 등 근거가 있는가 |
| 상세 스펙 | 소재 · 크기 · 용량 · 구성 정보가 있는가 |
| 사용법 · 관리 | 사용 방법이나 관리 방법을 안내하는가 |
| 후기 · 사회적 증거 | 후기, 판매량, 평점 등이 있는가 |
| 배송 · 교환 안내 | 배송 / 교환 / 반품 정보가 있는가 |
| 구매 유도 | 마지막에 구매를 권하는 장치가 있는가 |

## 4. 점수 (6항목 × 10점 = 60점)

| criterion | 10점 기준 | 감점 요인 |
|---|---|---|
| 첫 화면 후킹 | 첫 1 ~ 2화면 안에 대표 혜택 + 대표 이미지 | 브랜드 로고 / 공지만 있음, 혜택이 늦게 나옴 |
| 스토리 흐름 | 문제 → 해결 → 근거 → 정보 → 구매 유도 순서가 자연스러움 | 순서 뒤섞임, 같은 내용 반복 |
| 차별점 전달 | 차별점이 구체적(수치 / 비교)이고 반복 강조 | 막연한 형용사("최고", "프리미엄")만 있음 |
| 신뢰 근거 | 객관적 근거 + 후기 모두 있음 | 근거 없음, 출처 불명 수치 |
| 정보 완결성 | 스펙 / 사용법 / 배송 정보로 구매 전 질문 해소 | 핵심 스펙 누락, 배송 정보 없음 |
| 가독성 · 시각 구성 | 모바일에서 읽기 쉬운 글자 크기, 이미지와 문구 균형, 일관된 톤 | 작은 글씨 장문, 텍스트만 나열, 톤 불일치 |

- 각 점수에는 근거(`reason`)를 한국어 한두 문장으로 붙인다. 근거는 해당 섹션을 가리킨다.
- 점수는 상대 비교용 참고값이며 판매 성과를 보장하지 않는다(화면에 안내).

## 5. 개선 제안

- 3 ~ 7개. 점수가 낮은 항목과 체크리스트 누락 항목부터 다룬다.
- "무엇을 / 어디에 / 어떻게" 형태로 쓴다. 예: "첫 화면 아래에 실제 착용 사진과 함께 '하루 8시간 착용해도 편한' 같은 체감 혜택 문구를 추가".
- 경쟁 페이지 문구를 그대로 쓰라고 제안하지 않는다(DEC-007).

## 6. 내 사진 가이드 (`myImageGuide`)

섹션마다 "내 상품으로 이 섹션을 만들 때 준비할 사진"을 한 문장으로 쓴다. 예: "흰 배경 누끼컷 1장 + 손에 들고 있는 크기 비교컷 1장".
